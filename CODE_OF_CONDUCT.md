# Código de conducta

Este proyecto procura un entorno respetuoso, profesional y abierto a personas
con distintos niveles de experiencia.

Se espera que las contribuciones se centren en aspectos técnicos, se formulen
de manera constructiva y respeten la privacidad. No publique credenciales,
tokens, correos privados ni datos sensibles en incidencias, pruebas o ejemplos.

Las conductas abusivas, discriminatorias o de acoso no son aceptables. Las
incidencias deberán comunicarse de forma privada a la persona mantenedora del
repositorio.
